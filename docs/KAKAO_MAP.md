# 카카오맵 지도 · 로드뷰 설정 가이드

매물 상세 페이지의 **지도 / 로드뷰** 기능은 카카오맵 JavaScript SDK로 구현되어 있습니다.
([src/components/KakaoLocation.tsx](../src/components/KakaoLocation.tsx))

`NEXT_PUBLIC_KAKAO_MAP_KEY` 환경변수가 **없으면** 로드뷰 없이 OpenStreetMap 폴백 지도만
표시됩니다. 로드뷰를 활성화하려면 아래 절차로 카카오맵 키를 발급·등록해야 합니다.

---

## 1. 카카오 디벨로퍼스 — 앱 키 발급

1. https://developers.kakao.com → 내 애플리케이션 (소셜로그인용 앱과 동일 앱 사용 가능)
2. **앱 키** 화면에서 **JavaScript 키** 확보 → 이 값이 `NEXT_PUBLIC_KAKAO_MAP_KEY` 입니다.
3. **플랫폼 → Web** 에 서비스 도메인 등록 (등록 안 하면 지도 로드 시 도메인 오류):
   ```
   https://shopdaejang.hsweb.pics
   http://localhost:3000      ← 로컬 개발용
   ```
4. **카카오맵** 제품 사용 설정이 활성화되어 있는지 확인.

## 2. 환경변수

`.env.local` (개발) 및 배포 환경에 추가:

```env
NEXT_PUBLIC_KAKAO_MAP_KEY=<카카오 JavaScript 키>
```

`NEXT_PUBLIC_` 접두사가 붙어야 클라이언트(브라우저)에서 SDK 로드에 사용됩니다.
키 변경 후에는 재빌드/재배포가 필요합니다.

## 3. 동작 방식

| 상황 | 표시 |
|---|---|
| 키 있음 | 지도/로드뷰 탭 토글 — 카카오 지도 + 카카오 로드뷰 |
| 키 없음 / SDK 로드 실패 | OpenStreetMap(Leaflet) 폴백 지도, 로드뷰 미지원 |
| 로드뷰 탭 + 주변 파노라마 없음 | "이 위치는 로드뷰가 제공되지 않습니다" 안내 |

- 주소 → 좌표 변환은 카카오 `services.Geocoder` 사용. 시·도/구·군/동 + 상세주소를
  조합해 검색하고, 실패 시 시·도+구·군 으로 한 단계 축소 재시도.
- 로드뷰는 `RoadviewClient.getNearestPanoId` 로 반경 100m 내 가장 가까운 파노라마를 탐색.
- 매물 상세에서 **주소 공개** 매물만 지도/로드뷰가 노출됩니다. 비공개 매물은 동까지만
  안내됩니다.

## 4. 정확도

로드뷰·지도 핀 위치는 매물 등록 시 입력한 주소 기반입니다.
**상세주소(detail_address)** 가 입력된 매물일수록 핀이 실제 위치에 가깝게 표시됩니다.
상세주소가 없으면 동(洞) 중심 좌표로 표시되어 오차가 커질 수 있습니다.

## 5. 트러블슈팅

| 증상 | 원인 | 대응 |
|---|---|---|
| 지도가 OSM 으로만 표시됨 | 키 미설정 | `NEXT_PUBLIC_KAKAO_MAP_KEY` 추가 후 재배포 |
| 콘솔에 도메인 오류 | Web 플랫폼 미등록 | 카카오 콘솔 플랫폼에 도메인 추가 |
| 로드뷰 탭이 항상 "미제공" | 해당 좌표 반경 100m 내 로드뷰 없음 | 정상 (지방·골목 등). 반경은 코드에서 조정 가능 |
| 탭 전환 후 지도가 회색 | relayout 누락 | 코드에 이미 60ms 후 relayout 처리됨 |
